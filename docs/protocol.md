# QuickDrop WebSocket Protocol (v1)

All messages are JSON objects containing a `type` string and integer `version: 1`.

---

## 1. Client to Server Messages

### 1.1 Create Room (`room:create`)
Requested by the host device to initialize a new room.

```json
{
  "type": "room:create",
  "version": 1,
  "deviceName": "Windows PC"
}
```

- `deviceName` (optional, string, max 40 chars): Sanitized by the server.

### 1.2 Join Room (`room:join`)
Sent by the joining peer with the invitation token extracted from the URL fragment.

```json
{
  "type": "room:join",
  "version": 1,
  "roomId": "e98df89b9d3656abf276cd83ba239da1",
  "joinToken": "f784e1b827361a90c4d8123490aeef105432ab870912bcde",
  "deviceName": "Android Phone"
}
```

- `roomId` (required, string, 32 hex chars)
- `joinToken` (required, string, 48 hex chars)
- `deviceName` (optional, string, max 40 chars)

### 1.3 Text Message (`text`)
Relayed between room members during Milestone 1.

```json
{
  "type": "text",
  "version": 1,
  "clientMessageId": "msg-1730000000-abc1234",
  "text": "Hello from Android!"
}
```

- `clientMessageId` (optional, string, identifier generated by client)
- `text` (required, string, max 4096 characters)

### 1.4 Close Room (`room:close`)
Explicitly requested by the room owner to terminate the session.

```json
{
  "type": "room:close",
  "version": 1
}
```

---

## 2. Server to Client Messages

### 2.1 Room Created (`room:created`)
Sent to the room creator containing the single-use join token.

```json
{
  "type": "room:created",
  "version": 1,
  "roomId": "e98df89b9d3656abf276cd83ba239da1",
  "peerId": "c01827384910293847561029",
  "joinToken": "f784e1b827361a90c4d8123490aeef105432ab870912bcde",
  "expiresAt": 1793200600000
}
```

### 2.2 Room Joined (`room:joined`)
Sent to the joiner upon successful token validation.

```json
{
  "type": "room:joined",
  "version": 1,
  "roomId": "e98df89b9d3656abf276cd83ba239da1",
  "peerId": "a98471625340192837465019",
  "peerCount": 2,
  "ownerPeerId": "c01827384910293847561029",
  "ownerDeviceName": "Windows PC"
}
```

### 2.3 Peer Joined Notification (`peer:joined`)
Sent to the host when the guest device connects.

```json
{
  "type": "peer:joined",
  "version": 1,
  "peerId": "a98471625340192837465019",
  "deviceName": "Android Phone"
}
```

### 2.4 Text Relay (`text`)
Dispatched to the recipient. Note that `senderPeerId` and `deviceName` are securely stamped by the server.

```json
{
  "type": "text",
  "version": 1,
  "clientMessageId": "msg-1730000000-abc1234",
  "senderPeerId": "a98471625340192837465019",
  "deviceName": "Android Phone",
  "text": "Hello from Android!",
  "sentAt": 1793200123456
}
```

### 2.5 Text Acknowledgment (`text:ack`)
Sent back to the sender confirming delivery to the server relay.

```json
{
  "type": "text:ack",
  "version": 1,
  "clientMessageId": "msg-1730000000-abc1234",
  "sentAt": 1793200123456
}
```

### 2.6 Room Closed (`room:closed`)
Sent to all members when a room is terminated by the owner or due to disconnect.

```json
{
  "type": "room:closed",
  "version": 1,
  "reason": "closed_by_owner"
}
```

### 2.7 Peer Left (`peer:left`)
Sent to the remaining peer when the other disconnects.

```json
{
  "type": "peer:left",
  "version": 1,
  "peerId": "a98471625340192837465019",
  "reason": "disconnected"
}
```

### 2.8 Room Error (`room:error`)
Returned when an operation fails.

```json
{
  "type": "room:error",
  "version": 1,
  "code": "INVALID_TOKEN",
  "message": "Invalid room invitation token"
}
```

---

## 3. Standard Error Codes

| Code | Explanation |
| :--- | :--- |
| `INVALID_PAYLOAD` | Message exceeds max size (16 KiB) or is binary |
| `INVALID_MESSAGE` | Malformed JSON or schema validation failure |
| `INVALID_VERSION` | Version is not 1 |
| `INVALID_ROOM` | Room ID not found or room is inactive |
| `INVALID_TOKEN` | Invitation token hash mismatch |
| `TOKEN_USED` | Invitation token has already been consumed |
| `ROOM_FULL` | Room already has 2 members |
| `ROOM_EXPIRED` | Room exceeded idle TTL or max duration |
| `NOT_AUTHORIZED` | Caller does not own the room or is not a member |
| `RATE_LIMITED` | Too many requests within rate limit window |
| `ROOM_CAPACITY_EXCEEDED` | Server-wide concurrent room limit reached |
| `INTERNAL_ERROR` | Unexpected internal exception |
